## Users

Potential employers, collaborators, and clients evaluating Devom Brahmbhatt as a trader, engineer, and researcher. They arrive from a job application, a GitHub link, or a referral. ## Product Purpose

A portfolio for Devom Brahmbhatt — trader, engineer, researcher; Eastvale CA. The site's job is to make a fast, credible, memorable impression: this person builds systems that don't fail, and they care about the craft of doing it well. It is not a CV rendered as HTML. It is a designed artifact that communicates technical seriousness through its own execution.

Success: a visitor who arrives skeptical leaves convinced, and remembers the site.

## Brand Personality

Bold. Opinionated. Clean.

Not loud — decisive. The choices are few but committed. The type is big where it matters. The palette is deliberate. Nothing performs; everything communicates.

Voice: direct, precise, no filler. The copy reads like well-commented code — every line has a reason.

## Anti-references

- Dark-mode developer portfolio cliché: neon on black, glow effects, Matrix aesthetics, particle backgrounds.
- Over-animated: every hover triggers something, scroll-jacking, things moving for no reason.
- Generic SaaS landing page: hero metrics, feature-grid sections, gradient blobs, testimonial carousels.
- Boring résumé-as-website: no visual identity, white background, list of dates and job titles, nothing designed.

## Design Principles

1. **Every element earns its place.** If removing something doesn't cost anything, remove it. Decoration is not a design choice.

2. **Structure does the work.** Layout, type hierarchy, and whitespace carry the design. Color and motion are used to confirm decisions, not make them.

3. **Technical personality, not technical costume.** The server log is personality — it should feel like something Devom would actually write, not a prop. If a motif feels like a Halloween costume, cut it.

4. **Confident restraint over loud restraint.** Bold means decisive, not busy. One committed choice beats five hedged ones. Fewer elements, stronger presence.

5. **The site should be as clean as the code it represents.** Consistent patterns throughout, no one-off exceptions, every spacing and color decision systematic.

## Accessibility & Inclusion

Target WCAG AA. Prefers-reduced-motion honored (currently implemented in globals.css). Color contrast should be verified against the black canvas (`--color-bg`) for all text colors, including the muted variant and the two accent hues. No reliance on color alone to convey meaning.
